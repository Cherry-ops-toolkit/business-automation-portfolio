# Japanese Postal Code & Furigana Lookup

## Overview

A lightweight browser-based tool designed to support telephone order processing by retrieving Japanese address information from postal codes.

## Business Context

The company regularly received orders by phone from elderly customers. Obtaining accurate address information verbally could be challenging, often requiring repeated clarification and confirmation during calls.

To simplify this process, I created a tool that retrieves address details from a postal code, helping staff confirm customer addresses more efficiently while handling telephone orders.

## Key Features

- Look up Japanese address information by postal code
- Display retrieved address details in a simple interface
- Reduce the need for repeated verbal address confirmation
- Support more efficient telephone order processing

## Technologies

- HTML
- CSS
- JavaScript
- ZipCloud API

## How to Use

1. Open `index.html` in a web browser.
2. Enter the customer's postal code.
3. Retrieve the corresponding address information.
4. Use the result to help confirm the delivery address during the phone call.

An internet connection is required to access the external API.

## Business Value

This tool addresses a practical operational challenge by turning a repetitive, manual task into a simpler lookup process. It helps staff handle telephone orders more smoothly and reduces the effort involved in confirming Japanese addresses verbally.

## Scope and Limitations

- Address lookup depends on the external API's availability and returned data.
- Staff should confirm that the retrieved address matches the customer's intended delivery address.
- The tool supports address lookup and confirmation; it does not replace the company's order management system.
